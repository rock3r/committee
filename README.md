# Committee

Committee helps conference organisers review talk proposals. It imports Sessionize submissions, gathers evidence, and proposes topics and advisory findings for human review. It does not cast votes or make acceptance decisions.

**Status: pilot.** The local admin and reader have automated tests. Full-event live API import and deployed HTTPS userscript acceptance remain release checks. See [release readiness](docs/release-readiness.md).

![Review workspace with fictional proposals and a proposed claim finding](docs/images/review.png)

## Try it with fictional data

Requires Node.js 26 or later and Python 3.9 or later.

```sh
npm ci
npm run demo
```

Open `http://127.0.0.1:43129` and paste the token from the file printed in the terminal. The demo creates a new temporary directory each time; it never opens your real workspace or calls a paid provider. Stop it with Ctrl-C.

## Run your workspace

```sh
REVIEW_HELPER_DATA=/absolute/path/outside/the/repository npm start
```

Open the printed address. The server generates a local access token and prints its file location. Keep that token private. In **Data & sync**, connect a Sessionize JSON API endpoint, check its coverage, save the connection, then choose **Sync now**.

## How it fits together

```text
Sessionize API → local admin + SQLite → approved bundle → Worker + private R2
                         ↑                                   ↓
                research and detectors              reviewer site + userscript
```

The admin holds source data, credentials, research and draft findings. Analysis runs only when requested. Publication sends a reviewed subset to the hosted reader. Reviewers use invitation codes; they do not need access to the admin machine. Hosting identifiable submissions still requires permission from the event owner.

## Development

```sh
npm ci
npm run check
```

This runs ESLint, TypeScript checking, backend/Worker tests, frontend tests, Python collector tests and the reader asset build. Tests use synthetic records and do not require provider keys. CI runs the same command on Linux.

The repository contains no conference dataset. Screenshots use fictional records generated by `scripts/demo.ts`. Licensed under [Apache 2.0](LICENSE).
